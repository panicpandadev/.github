## 02 — The studio

> **Small team. Probably overthinking it.**

Panic Panda is an indie game studio focused on **clear, readable mechanics**, a **bold and consistent visual identity**, and **deeply refined games**. We build atmospheric, engaging, chaotic multiplayer experiences—but every project starts with the same question:

<h3 align="center"><i>How will the player have the most fun?</i></h3>

<table>
  <tr>
    <td width="33%" valign="top">
      <h3>◆ HOOK FIRST.</h3>
      <p>Understandable in seconds.<br />Interesting for much longer.</p>
    </td>
    <td width="33%" valign="top">
      <h3>◆ TOUCH MATTERS.</h3>
      <p>Objects, physics and interactions should feel satisfying first.</p>
    </td>
    <td width="33%" valign="top">
      <h3>◆ PERSONALITY WINS.</h3>
      <p>Clean production, strange details and a little bit of ridiculousness.</p>
    </td>
  </tr>
</table>
